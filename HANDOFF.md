## O que é este projeto

**Curso de formação para professores de dança e gestores.**

- **Nome:** Ensinar é Algo Vivo
- **Público:** professores de dança que já dão aula (qualquer modalidade) + gestores
- **Duração:** 48h (28h presenciais + 20h EAD)
- **Formato:** dois fins de semana + a semana entre eles
- **Pergunta central:** Como eu auxilio a evolução do processo de aprendizagem do balé
  a partir das demandas singulares de cada corpo?

**Este repositório é só documentação.** Não há código, não há ferramenta.

**A ferramenta** (o sistema de ciclos) está em outro repositório, referenciado em
`FERRAMENTA.md`. **O agente não tem permissão de escrita no projeto Dança.**

## Estado do projeto

### Decidido

- **Nome:** Ensinar é Algo Vivo
- **Público:** professores de dança (qualquer modalidade) + gestores
- **Carga horária:** 48h (28h presenciais + 20h EAD)
- **Formato:** dois fins de semana + a semana entre eles
  - Fim de semana 1: 4 encontros de 4h (sáb manhã, sáb tarde, dom manhã, dom tarde)
  - Semana: aplicação real na escola do participante + consulta EAD (4h/dia, janela
    aberta, 5 dias úteis = 20h)
  - Fim de semana 2: 3 encontros de 4h (sáb manhã, sáb tarde, dom manhã)
- **Domingo à tarde:** livre nos dois fins de semana
- **Estrutura:** 3 módulos (infantil, juvenil/adulto, acompanhamento) + prático
- **Prático:** anamnese → planejamento (10 blocos) → aula (5 min interna; aula real na
  semana) → lançamento → relatório → leitura → apresentação → debate
- **O debate não é julgamento** — é sobre dados e leitura de dados
- **A ferramenta é agnóstica de modalidade**
- **O sistema não faz síntese** — mostra a lista do que mudou
- **A linha de base se encadeia** — LB zero no PO; LB da aula N+1 é o resultado da aula N
- **O professor decide** — o sistema sugere, ele confirma ou corrige

## O que está pendente

### Decisões em aberto

- **A exposição do professor** ao dar aula para os pares (e ao ser aluno dos colegas).
  Alternativa: convidar os próprios alunos.
- **O registro do debate** — o que emerge no debate entra na cadeia como elo novo, ou
  o debate é só formativo?
- **O formato do confronto de leituras** — como se registra o que cada um viu, sem que
  vire debate?
- **A anamnese** — como levantar a LB zero do grupo em poucos minutos? **E em que
  encontro ela acontece?** (o `PLANO.md` não conseguiu fixá-lo)
- **A EAD** — como as 4h/dia são usadas: janela aberta, agenda fixa, ou misto?
